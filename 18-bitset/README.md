# 18. 비트셋

11번 블룸 필터에서 비트 배열을 **쓰기만 하고 안 가르쳤습니다.** 여기서 제대로 봅니다.

자바에서 `boolean[]`은 원소 하나가 **1비트가 아니라 1바이트**입니다.
JVM이 바이트 단위로 주소를 잡기 때문입니다. 100만 개면 1MB, 비트로 누르면 125KB.
**8배 차이**이고 그것만으로도 이유가 됩니다.

**그런데 진짜 이유는 메모리가 아닙니다.**

| | boolean[] | long[] 비트셋 |
|---|---|---|
| 100만 비트 메모리 | 1,000,000 바이트 | **125,000 바이트** |
| 교집합 걸음 수 | 1,000,000 | **15,625** |
| 개수 세기 | 100만 번 비교 | 15,625번 popcount |
| 다음 켜진 비트 | 하나씩 본다 | **꺼진 워드는 통째로 건너뛴다** |

두 번째 줄이 핵심입니다. `a[i] & b[i]` 하나가 **비트 64개를 처리합니다.**

이게 데이터베이스의 비트맵 인덱스가 존재하는 이유입니다.
"성별=남 AND 지역=서울 AND 등급=VIP"를 각 조건의 비트맵을 and 하는 것으로 답합니다.
행을 하나씩 보는 대신 **워드 단위로 접습니다.**

## 세 구현

| | 무엇 | 언제 |
|---|---|---|
| `BooleanArrayBitSet` | `boolean[]` 그대로 | 기준선. **먼저 만들어보고 문제를 본다** |
| `WordBitSet` | `long[]`에 눌러 담는다 | 대부분의 경우 |
| `SparseBitSet` | 켜진 워드만 맵에 | **워드의 1/6 미만**이 켜질 때 |

`SparseBitSet`은 빽빽하면 집니다. 맵 엔트리 하나가 워드 하나(8바이트)보다 훨씬 비쌉니다.
05번(체이닝 대 개방주소), 09번(맵 트라이 대 배열 트라이), 14번(맵 대 배열)에서 본 거래입니다.

## 특히 생각해볼 것

**1. 꼬리 비트가 이 문제의 함정입니다.**
크기 70이면 워드 2개(128비트)라 **58비트가 남습니다.** `set()`은 범위를 검사하니
남는 자리가 켜질 일이 없지만, **워드를 통째로 다루는 연산은 그 자리를 켭니다.**
정리 마스크 자체에도 함정이 둘 더 있고, 이 셋이 각각 다른 테스트로 잡힙니다.

**2. 같은 계약인데 상대가 누구냐에 따라 비용이 다릅니다.**
`and(other)`에서 상대의 타입이 걸음 수를 64배 가릅니다.
실무 라이브러리가 `instanceof`로 빠른 길을 여는 것이 이 모양입니다.

**3. 자바의 long 시프트는 시프트 수를 자동으로 64로 나눈 나머지로 씁니다.**
그래서 `1L << bit`만 써도 **우연히 맞습니다.** 변종을 돌려보면 98개가 다 통과합니다.
그래도 `bit & 63`을 명시하세요. **우연에 기대는 코드는 읽는 사람이 확신할 수 없습니다.**
(11번에서 같은 이유로 변종 하나가 동치로 판명됐습니다.)

**4. 테스트가 구별하지 못하는 방어 코드가 또 나옵니다.**
`nextSetBit`의 "크기 밖이면 -1" 검사는 `trimTail`이 제대로 동작하면 **도달할 수 없습니다.**
꼬리 비트가 켜질 방법이 없기 때문입니다. 변종으로 지워도 98개가 다 통과합니다.

11번 블룸 필터의 `h2 == 0`, 16번 레드블랙 트리의 "뿌리를 빨갛게"에 이어 세 번째입니다.
**세 번 나왔으면 우연이 아닙니다.** 불변식을 지키는 코드가 여럿이면
그중 하나가 나머지를 여벌로 만듭니다. 지우지 않고 남기되 **테스트가 못 잡는다는 것을 알고** 남깁니다.

**5. 문제 1의 `p*p`.** 체에서 `2p`가 아니라 `p*p`부터 지우는 것은
**답은 같고 비용만 다릅니다.** 변종으로 `2p`부터 돌게 해도 98개가 다 통과합니다.
둘 다 O(n log log n)이고 상수만 다릅니다. **정직하게 적어둡니다.**

**6. 문제 2의 0/0.** 둘 다 빈 집합인 경우를 정하지 않으면 `NaN`이 조용히 퍼집니다.

**7. 문제 3의 부분집합 열거.** 0부터 mask까지 전부 도는 것과 달리
**부분집합 개수만큼만** 돕니다. 종료 조건이 함정입니다.
