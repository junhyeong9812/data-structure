# 07. 힙 (우선순위 큐)

06번 이진 탐색 트리는 **전부** 정렬 상태를 유지했습니다. 그래서 순서에 관한 무엇이든 물을 수 있었습니다.
그런데 실무에서는 그렇게까지 필요 없는 경우가 훨씬 많습니다.
작업 큐, 다익스트라, 이벤트 스케줄러는 전부 **"지금 가장 급한 것 하나"** 만 알면 됩니다.

힙은 딱 그만큼만 합니다. **부분 순서**만 지킵니다.
부모가 자식보다 앞선다는 것만 보장하고 **형제끼리는 아무 관계가 없습니다.**
덜 지키니까 더 쌉니다. 그게 이 자료구조의 거래입니다.

| 질문 | BST | 힙 |
|---|---|---|
| 가장 앞선 것 | O(log n) | **O(1)** |
| 넣기 / 가장 앞선 것 빼기 | O(log n) | O(log n) |
| 임의의 키 찾기 | **O(log n)** | O(n) |
| 정렬 순회 | **O(n)** | O(n log n) |

## 순서대로 하세요

```
1. SortedListHeap   정렬해서 끼워 넣는다. 동작은 맞다. 넣기가 O(n) 이다
2. BinaryHeap       배열로 트리를 표현한다. 넣기가 O(log n) 이 된다
3. MinHeap/MaxHeap  BinaryHeap 에 비교자만 끼운다. TODO 가 없다
```

1번을 건너뛰지 마세요. `SortedListHeapTest.insertCostGrowsQuadratically` 가
원소를 몇 번 밀었는지 세어 보여줍니다. 1000개를 넣으면 약 50만 번 밉니다.

## 두 가지 핵심 발상

**1. 전부 정렬할 필요가 없다.** 부모가 자식보다 앞서기만 하면 맨 위가 가장 앞선 것입니다.
`BinaryHeapTest.isNotFullySorted` 가 그걸 확인합니다. 전체 정렬을 보장하면 그건 힙보다 비싼 구조입니다.

**2. 완전 이진 트리는 배열로 표현할 수 있다.** 빈틈없이 채워진 트리면 위치를 계산으로 압니다.

```
부모   (i - 1) / 2
왼쪽    2i + 1
오른쪽  2i + 2
```

02번 연결 리스트에서 노드마다 참조를 들고 있던 것과 대비됩니다.
**구조가 규칙적이면 그 규칙을 계산으로 대신할 수 있습니다.** 포인터가 사라집니다.

## 특히 생각해볼 것

**1. `siftDown` 에서 어느 자식과 바꾸는가** — 두 자식 중 **더 앞선** 쪽과 바꿔야 합니다.
뒤처진 쪽과 바꾸면 그 자식이 다른 자식보다 뒤처져 힙 성질이 다시 깨집니다.
한 글자 차이인데 변종을 돌려보면 48개 중 13개가 무너집니다.

**2. `poll` 에서 구멍을 무엇으로 메우는가** — 맨 위를 빼면 구멍이 생깁니다.
트리 모양을 안 깨고 메울 수 있는 것은 **마지막 원소** 하나뿐입니다.
자식을 올리면 중간에 빈 자리가 생겨 완전 이진 트리가 아니게 되고, 그러면 인덱스 계산이 무너집니다.

**3. 최소 힙과 최대 힙의 차이는 비교 방향 하나** — `MinHeap` 과 `MaxHeap` 에 TODO 가 없는 이유입니다.
힙 로직을 한 줄도 다시 쓰지 않습니다.

**4. 문제 2번이 뒤집혀 보입니다.** "k 번째로 **큰** 값"을 찾는데 **최소 힙**을 씁니다.
k 개만 들고 있으면 그중 가장 작은 것이 곧 답이고, k+1 개가 되면 **가장 작은 것을 버려야** 하기 때문입니다.
"가장 작은 것을 O(1) 로 보고 O(log n) 으로 버린다"가 정확히 최소 힙입니다.

**5. 문제 3번이 이 문제집에서 힙의 진가입니다.** 중앙값을 알려면 전체 순서가 필요 없습니다.
작은 절반과 큰 절반으로 나눠 두고 **경계에 있는 값**만 알면 됩니다.
작은 절반에서는 가장 큰 값, 큰 절반에서는 가장 작은 값. 그게 정확히 최대 힙 하나와 최소 힙 하나입니다.

지켜야 할 것이 둘입니다. 크기 균형(차이가 1 이하)과 순서(작은 절반의 어떤 값도 큰 절반보다 크지 않음).
**한쪽에 넣었다가 꼭대기를 넘기면** 순서 조건이 저절로 지켜집니다. 어느 쪽에 속하는지 따로 판단할 필요가 없습니다.

**6. 정수 나눗셈** — 짝수 개일 때 두 꼭대기의 평균을 `/ 2` 로 내면 1.5가 1이 됩니다. `/ 2.0` 이어야 합니다.
