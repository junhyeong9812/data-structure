# 30. 인터벌 트리

13번 세그먼트 트리는 **고정된 배열의 구간**을 다뤘습니다. 인덱스가 이미 정해져 있었습니다.
25번 KD-트리는 **점**을 다뤘습니다. 여기서는 **구간 자체가 자료**이고, 겹침을 묻습니다.

```
회의실 예약 [9,11), [10,12), [14,15) 가 있을 때
  "[10:30, 11:30) 과 겹치는 예약을 전부"      "새 예약 [10,11) 을 넣어도 되나"
```

전수 조사면 O(n)입니다. 예약이 10만 개면 매번 10만 번 봅니다.

| | 무엇을 담나 | 무엇을 묻나 |
|---|---|---|
| 13번 세그먼트 트리 | 배열의 값 | 인덱스 구간의 집계 |
| 25번 KD-트리 | 점 | 사각형 안의 점, 가까운 점 |
| **30번 인터벌 트리** | **구간** | **겹치는 구간** |

## 06번에 필드 하나를 더한 것입니다

시작점으로 정렬한 BST에 `maxEnd` 하나를 답니다. **이 부분트리에 있는 구간들의 끝점 최댓값**입니다.
그 한 필드가 가지치기를 만듭니다.

```
왼쪽 부분트리의 maxEnd 가 질의 시작 이하  ->  왼쪽은 볼 필요가 없다
지금 노드의 시작이 질의 끝 이상            ->  오른쪽도 볼 필요가 없다
```

구간 4000개, 질의 200번, 방문한 노드 수입니다(시간이 아니라 걸음 수).

| | 전수 조사 | 인터벌 트리 |
|---|---|---|
| `findAll` 200번 | 800,000 | **5,229** |
| `findAny` 200번 | 182,017 | **2,688** |

**가지치기 두 줄 중 한 줄만 지워도 답은 그대로입니다.** 방문만 41만 번대로 뜁니다.
그래서 시간을 안 재고 걸음 수를 셉니다.

## 반개구간 [start, end) 으로 정했습니다

`[9,11)` 과 `[11,13)` 은 **안 겹칩니다.** 닫힌 구간으로 잡으면 11시 한 점을 공유해서
"겹친다"가 나오고, 그러면 붙여 잡은 회의를 예약할 수 없습니다. 이 결정이 `overlaps` 한 줄,
스위핑의 이벤트 순서, `merge` 의 합치기 조건을 전부 정하는데 **셋의 부등호가 서로 다릅니다.**

## 좌표 압축

13번 세그먼트 트리로 이 문제를 풀려면 배열 한 칸이 좌표 한 개입니다. 좌표 범위가 10억이면
4n 관행으로 **40억 칸**이고, 등장하는 좌표만 세면 구간 1000개에 좌표는 2000개라 **8000칸**입니다.
50만 배입니다. 겹침은 좌표의 **크기 비교**로만 정해지므로 순서만 보존하면 답이 안 바뀝니다.

## 특히 생각해볼 것

**1. `maxEnd` 갱신을 빠뜨리면 예외가 안 납니다.** 낡은 값은 "여기 아래엔 볼 게 없다"는
거짓말이 되어 **답이 조용히 빠집니다.** 삭제 쪽은 틀리는 방향이 둘입니다.

**2. `findAny` 가 한 갈래로만 내려가도 되는 이유를 납득해야 합니다.**
왼쪽으로 갔다가 못 찾으면 오른쪽에도 없습니다. 왜 그런지 설명할 수 있어야 합니다.

**3. 트리가 필요 없는 문제를 일부러 넣었습니다.** `merge` 와 `maxConcurrent` 는 정렬 한 번에
훑기로 끝납니다. **질의가 한 번이면 정렬이 이깁니다.** 트리가 이기는 것은 질의가 반복될 때이고,
자료가 아니라 질의 횟수가 자료구조를 정합니다. `maxConcurrent` 는 좌표가 같을 때 무엇을 먼저
처리하느냐가 전부입니다. 어긋나면 이어달리기 회의 넷이 방 두 개를 쓴다고 나옵니다.

## 한계 (고칠 수 없는 성질)

**1. 빈 부분트리의 `maxEnd` 를 0으로 두면 좌표가 음수일 때 무너집니다.**
0은 최댓값의 항등원이 아닙니다. 그 변종은 음수 좌표 대조 하나만 깨뜨렸고,
증상이 "답이 12개인데 null" 이었습니다. 13번의 "최소 트리에 항등원 0" 과 같은 계열입니다.

**2. 정렬된 순서로 넣으면 연결 리스트가 됩니다.** 06번과 똑같습니다. 1000개를 정렬 순서로 넣으면
높이가 **1000**(흩어 넣으면 30)이고, 같은 질의에 `findAll` 방문이 **506 대 17**, `findAny` 가
**501 대 13** 입니다. 답은 맞고 걸음 수만 무너집니다.

**3. 결과가 크면 집니다.** `O(log n + k)` 의 k가 n이면 O(n)입니다. 전부 한 점을 덮는 1000개에
그 점을 물으면 방문이 **1000**, 전수 조사와 같습니다. 25번의 "모든 점이 같은 거리" 와 같은 자리입니다.

**4. 변종 24개를 심어 전부 잡혔습니다.** 다만 가지치기 부등호를 `>=` 로 바꾸는 변종 셋은
무작위 대조로는 안 걸렸습니다. 좌표가 정확히 같아야 드러나서 경계 측정을 따로 넣었습니다.
