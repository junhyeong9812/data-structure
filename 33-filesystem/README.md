# 33. 인메모리 파일 시스템

파일 시스템을 두 가지로 만듭니다.

```
TreeFileSystem       이름 -> 자식 맵을 층층이 쌓는다. 진짜 트리
FlatPathFileSystem   전체 경로가 키인 맵 하나. 트리가 없다
```

**두 번째가 훨씬 쉽고, 계약 테스트 68개를 똑같이 통과합니다.**

그러면 트리는 왜 있는가. 이 박스는 그 질문 하나입니다.

## 답이 같은데 왜 다른 구조를 쓰는가

`/src` 아래 항목 341개를 `/dst` 로 옮겨봅니다.

| | 키를 다시 쓴 개수 |
|---|---|
| 트리 | **1** |
| 평면 맵 | **341** |

트리는 부모에서 떼어 다른 부모에 붙입니다. 그 아래 무엇이 몇 개 있든 상관없습니다.
평면 맵은 경로가 곧 키라서, **그 아래 있던 항목의 키를 전부 다시 씁니다.**

깊이를 1, 2, 3으로 늘려도 트리는 계속 1입니다. 평면 맵은 21, 85, 341로 늡니다.

## 그런데 평면 맵이 이기는 곳도 있습니다

깊이 21인 경로 하나를 읽으면 **트리는 22번 내려가고 평면 맵은 해시 한 번**입니다.
정직하게 적어둡니다. 트리가 늘 이기는 것이 아니라 **무엇을 물어보느냐가 정합니다.**

| 물어보는 것 | 트리 | 평면 맵 |
|---|---|---|
| 이 경로 하나 열기 | 22 | **1** |
| 이 디렉터리의 자식 | **2** | 343 |
| 여기부터 찾기 | **3** | 345 |
| 디렉터리 옮기기 | **1** | 341 |
| 복사하기 | 85 | 85 |

패턴이 보입니다. **경로 하나를 짚는 일은 평면 맵이, 관계를 묻는 일은 트리가** 이깁니다.
평면 맵에는 부모와 자식 관계가 어디에도 안 적혀 있어서 매번 전체를 훑어 되살립니다.

마지막 줄도 중요합니다. `cp` 에서는 **구조가 아무것도 안 구해줍니다.**

## 특히 생각해볼 것

**1. 경로 규칙이 두 구현의 공통 조상입니다.** 그래서 여기가 틀리면 **둘이 똑같이 틀립니다.**
서로 대조해도 안 잡힙니다. `PathsTest` 가 따로 있는 이유입니다.
대조로 못 잡는 것은 대조 밖에서 봐야 합니다.

**2. `..` 이 루트를 넘어가려 할 때 무엇을 할지가 이 박스의 첫 함정입니다.**
막지 않으면 경로가 루트 밖을 가리킵니다. 실제 시스템에서는 그 자리가 취약점이고
(`../../etc/passwd` 로 시작하는 사고가 전부 여기입니다), 여기서는 조용한 오답이 됩니다.

**3. 조상 판정을 문자열 접두사로 하면 `/ab` 가 `/a` 의 자손이 됩니다.**
`mv /a /z` 한 번에 관계없는 `/ab` 가 `/zb` 로 끌려갑니다. 조각 단위로 봐야 합니다.

**4. 디렉터리를 자기 안으로 옮기면 서브트리가 통째로 사라집니다.** 예외도 안 납니다.
트리에서 떨어져 나가 아무도 못 닿는 곳에 남을 뿐입니다.

**5. 이름과 내용을 갈라놓으면 하드 링크가 됩니다.** 이름은 디렉터리에, 내용은 `Blob` 에.
그 순간 **구조가 트리가 아니게 됩니다.** 자식이 부모를 둘 가지기 때문입니다.
그러면 "지운다"의 뜻도 바뀝니다. **마지막 이름이 사라질 때만** 내용이 죽습니다.

11번 블룸 필터에서 "A를 지우면 B가 같이 사라진다"고 했던 것과 같은 모양입니다.
거기서는 못 고쳤고(비트를 나눠 쓰니까) 여기서는 세어서 고칩니다.

**6. 그래서 `cp` 와 `link` 는 한 글자 차이입니다.** 새 `Blob` 을 만드느냐 그대로 가리키느냐.
그대로 가리키면 복사가 아니라 링크이고, **사본에 쓴 것이 원본에 비칩니다.**
26번 영속 자료구조에서 구조를 공유해도 됐던 것은 그것이 불변이었기 때문입니다.
`Blob` 은 가변이라 공유하면 안 됩니다.

**7. 무작위 대조가 이 박스의 주력 검증입니다.** 연산 3,200번을 두 구현에 똑같이 넣고
**연산 하나마다** 전체 상태를 문자열로 찍어 비교합니다. 끝에서 한 번만 비교하면
어디서 갈렸는지 찾느라 처음부터 다시 재현해야 합니다. 한쪽만 예외를 던지는 것도 불일치로 세고,
"둘 다 던졌다"가 쌓여 아무것도 대조 안 하는 상태를 막으려고 실제 수행된 연산 수를 따로 셉니다.

**8. 변종 10개를 심어 전부 잡혔습니다.** 다만 `mkdirs` 중간의 파일 검사를 지운 변종은
처음에 살아남았습니다. 검사를 지워도 결국 다른 예외가 나서, **예외의 종류를 안 보는**
테스트로는 구별이 안 됐습니다. 그 하나를 위해 테스트를 더 넣었습니다.
